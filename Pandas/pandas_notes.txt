Pandas Notes

- Data Manipulation: Changing, organizing, or preparing data to make it useful and easier to understand. To clean and structure raw data for better usability.
- Data Analysis: Extracting patterns, trends, and insights from the data to solve problems.
- Series: A one-dimensional labeled array that can hold any data type (integers, floats, strings, or even python objects). Each element has a unique label called an index. Used to track changes or patterns over time.
- Data Frame: A 2D labeled data structure in Pandas, like a table in a database, Excel spreadsheet, or SQL table. It has rows and columns.
    - Rows -> indices (labels)
    - Columns -> names (labels)
- Encoding: Convert text to formats that computers can store and read.
    - Set encoding to different styles like 'utf-8' or 'latin1' (whichever supported).
    - No need for encoding if it accepts in the first case.
    - Example: df = pd.read_csv("sales_data_sample.csv", encoding='latin1')
- Other read functions:
    - Excel: df = pd.read_excel("File.xlsx")
    - JSON: df = pd.read_json("file.json")
- Note: File should be in the same directory as code.
- Data on cloud: Can be read through different libraries (e.g., Google Cloud -> gcfs library).
- After Data Manipulation, save the file.

- For saving the file: 
    - df.to_csv("Output.csv", index=False) -> creates the file output.csv in the same directory
    - df.to_excel(...)
    - df.to_json(...)
- Understanding the data:
    - Understand the data set.
    - Identify the problems.
    - Plan next steps.
- ROWS:
    - To analyze initial and final rows, use head() and tail() (default 5 rows).
- df.info():
    - Gives all info about the data and summarizes the data set.
    - Shows: no. of rows and columns, memory usage, data types, column names, non-null values, etc.
- df.describe():
    - Prints all statistical data of all columns: count (non-null values), mean, standard deviation, minimum, maximum.
    - Quartiles: 25% (First), 50% (Second), 75% (Third).
- df.shape: Number of rows and columns.
- df.columns: Names of columns.
- Data Manipulation:
    - Select Columns: Using square braces.
    - Filter Rows: Using Boolean conditions.
- To select single/multiple columns:
    - column = df["ColumnName"]
    - subset = df[["Column1", "Column2", ...]]
- Filtering Rows based on condition:
    - Single: filter_rows = df[df["Salary"] > 50000]
    - Multiple: filter_rows = df[(df["Salary"] > 50000) & (df["Column2"] < 80000)]
    - Use '|' for 'or' condition.
- Adding columns:
    - Using square braces: df["Bonus"] = df["Salary"] * 0.1
    - Using insert() method: df.insert(location, "ColumnName", somedata)
- Modifying a value:
    - Use .loc: df.loc[Row_index, 'ColumnName'] = NewValue
- Removing columns:
    - Using df.drop: df.drop(columns=["ColName"], inplace=True)
    - Does not create a new df, modifies the current one.
- Handling Missing Data:
    - Types: NaN (Not a Number, for object data types), None.
    - isnull(): Returns Boolean (True if NaN/missing, False if present).
    - No. of missing values: df.isnull().sum() (Output: count of missing values in each column).
- Removing Rows/Columns with missing values:
    - Using dropna(): df.dropna(axis=0, inplace=True) (axis=0 for rows, axis=1 for columns).
- Adding new values in place of NaN (fillna):
    - df.fillna(value, inplace=True)
- To replace NaN with the mean (in modern pandas):
    - df['cn'] = df['cn'].fillna(df['cn'].mean(), inplace=True)
    - This replaces all NaN values in the column with the mean of other values in that column.
- Interpolation:
    - Fills NaN values with an estimated value (e.g., linear).
    - df['cn'] = df['cn'].interpolate(method='linear')
- Using interpolation:
    - Time series data (data changing with time).
    - Numeric data with trends.
    - Avoid dropping rows.
- Sorting Data:
    - Using sort_values(): df.sort_values(by="cn", ascending=True/False, inplace=True).
    - Sorting by multiple columns: Pass a list of column names.
- Calculating mean, min, max:
    - df['cn'].mean()
    - df['cn'].min()
    - df['cn'].max()
- Grouping:
    - Done on the basis of a column.
    - obj = df.groupby('cn1')['cn2'].sum()
    - Groups are created based on unique values in the column.
    - Certain conditions are performed after grouping to give output.
    - Grouping by multiple columns: Pass a list in place of the column name.
- Common Aggregation terms:
    - sum(), mean(), count(), min(), max(), std().
- Merging dataframes:
    - pd.merge(df1, df2, on='cn', how='type_of_joint')
    - Joins:
        - inner: Only outputs keys which are matched.
        - outer: All values; non-present ones filled with NaN.
        - left: Keeps all values of left df (and matched ones of right).
        - right: Keeps all values of right df (and matched ones of left).
        - Cross join: Basically gives a Cartesian product of two DataFrames. If df1 has m rows and df2 has n rows, the result has m * n rows.
- Concatenation: Joins 2 or more DataFrames vertically (rows) or horizontally (columns).
    - Example: pd.concat([df1, df2], axis=0, ignore_index=True)
    - axis=0 -> Vertically (default).
    - axis=1 -> Horizontally.
    - ignore_index=True: Makes new indexes for the combined DataFrame.

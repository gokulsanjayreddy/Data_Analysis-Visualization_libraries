Numpy Notes

- Numpy: Used to handle large datasets.
- By using python loops it takes a lot of time to handle very large datasets.
- By using numpy arrays we can handle very large data and perform calculations on it within ms.
- Arrays: Collection of Numbers/Values which are stored in an organised way.
    - 1d array -> like a Row (just like a Matrix).
    - 2d array -> like a Table (with rows and columns).
    - 3d array -> stacking of 2d arrays.
- Creating arrays from python lists:
    - import numpy as np
    - arr = np.array([1, 2, 3, 4])
    - print(arr) -> prints [1 2 3 4]
- With default values:
    - import numpy as np
    - arr = np.zeros(3)
    - print(arr) -> prints [0. 0. 0.]
    - (Can also be 3x4, 2x3, etc.)
    - Replace zeros with ones to create array of 1's.
    - full(shape, value): Value that should be in array like zeros/ones (e.g., 2x3(2,3) etc.).
- Creating sequences of numbers in numpy:
    - Using arange(): like arange(start, stop, step)
    - import numpy as np
    - arr = numpy.arange(1, 10, 2)
    - print(arr) -> prints [1 3 5 7 9]
- Creating Identity Matrices:
    - Using eye(size) (e.g., eye(3) -> 3x3 identity matrix).
- Attributes in python Numpy:
    - Shape:
        - import numpy as np
        - arr = np.array([[1, 2, 3], [4, 5, 6]])
        - print(arr.shape) -> prints (2, 3) (2 rows, 3 columns).
    - Size (Total number of elements in an array).
    - ndim: number of dimensions in an array.
    - d-type: data type of elements (in the array) like int, float, str, etc.
- Converting the data type of numpy array:
    - Using astype()
    - import numpy as np
    - arr = np.array([1.2, 2.5, 3.8])
    - int_arr = arr.astype(int)
    - print(int_arr) -> prints [1 2 3]
- Performing mathematical operations on Numpy arrays:
    - import numpy as np
    - arr = np.array([10, 20, 30])
    - print(arr + 5) -> adds 5 to every element
    - print(arr * 2) -> multiplies 2 to every element
    - print(arr ** 2) -> squares every element
- Aggregation functions: summarizes the data set.
    - np.sum(array) -> adds all
    - np.mean(array) -> mean cal
    - np.min/max(array) -> min/max
    - np.std(array) -> cal std. deviation
    - np.var(array) -> cal variance
- Indexing & Slicing in numpy:
    - Indexing: picking up a single element in np.array.
    - Slicing: picking up multiple elements in np.array (start, stop, step).
    - Fancy Indexing: selecting a list of elements using a list of indices.
    - Boolean Masking: giving a condition to filter the elements and picking up elements.
- Indexing in numpy:
    - 0 1 2 ... -3 -2 -1 (zero indexing, negative indexing).
    - array[index] -> 1d array.
    - array[row, column] -> 2d array.
    - import numpy as np
    - arr = np.array([10, 20, 30, 40, 50])
    - print(arr[0]) -> prints 10.
- Slicing in numpy:
    - Give start, stop, step (default value 1).
    - arr[1:5] -> prints elements in the index (1, 2, 3, 4).
    - [:4] -> takes 0 there.
    - [::-1] -> Reverse the array.
- Fancy indexing:
    - import numpy as np
    - array = np.array([10, 20, 30, 40, 50, 60])
    - print(array[[0, 2, 4]]) -> prints 10 30 50
- Boolean Masking:
    - import numpy as np
    - arr = np.array([10, 20, 30, 40, 50, 60])
    - print(arr[arr > 25]) -> prints elements > 25
- Reshaping & Manipulating arrays:
    - Changing dimension/shape of array without modifying data.
    - e.g., 1d -> 2d, 2d -> 3d (it creates copy / just another view).
    - import numpy as np
    - arr = np.array([1, 2, 3, 4, 5, 6])
    - reshaped_arr = arr.reshape(2, 3) (2 rows, 3 columns).
    - print(reshaped_arr) -> prints [[1 2 3], [4 5 6]].
    - ravel() -> changes view (affects original array).
    - flatten() -> copy (does not affect original array).
- Modification of a numpy array:
    - Insert: Inserts a particular element at a particular index.
    - np.insert(array, index, value, axis=None).
    - axis=0 -> row wise insertion.
    - axis=1 -> column wise insertion.
    - import numpy as np
    - arr = np.array([10, 20, 30, 40])
    - narr = np.insert(arr, 2, 100)
    - print(narr) -> prints [10 20 100 30 40]
    - if axis=None is taken then the element is inserted in flattened copy.
- Append array:
    - Adds at the end of another Array.
    - import numpy as np
    - arr = np.array([10, 20, 30])
    - narr = np.append(arr, [40, 50, 60])
    - print(narr) -> prints [10 20 30 40 50 60]
- Concatenate:
    - np.concatenate((array1, array2), axis)
    - axis=0 -> vertical Stacking (Row wise)
    - axis=1 -> Horizontal stacking (column wise)
- Removing elements from Array:
    - np.delete(array, index, axis)
- Stacking of Multiple Arrays:
    - vstack() -> Row wise stacking
    - hstack() -> column wise stacking
    - import numpy as np
    - arr1 = np.array([1, 2, 3])
    - arr2 = np.array([4, 5, 6])
    - print(np.vstack((arr1, arr2))) -> vstack prints [[1 2 3], [4 5 6]]
    - By using hstack we get output as [1 2 3 4 5 6]
- Splitting an array:
    - np.split() -> splits into equal parts
    - np.hsplit() -> split horizontally
    - np.vsplit() -> split vertically
- Broadcasting: Numpy way of performing operations on large datasets.
- How Numpy handles Arrays of Different shapes?
    - Matching Dimension: handles normally.
        - [1 2 3] + [4 5 6] -> [5 7 9]
    - Expanding single elements:
        - [1 2 3] + 10 -> [11 12 13]
    - Incompatible shapes:
        - [1 2 3] + [1 2] -> Gives an error (size 3, size 2)
- Vectorization: to apply mathematical operations to entire arrays at once rather than using python loops.
- Alternative to loops in python.
- Handling Missing values:
    - np.isnan() -> detect missing values
    - np.nan_to_num() -> to replace missing values in another function/num
    - np.isinf() -> to detect infinite values
- NaN -> Not a number.
- isNaN returns a boolean True (or False, true for NAN values).
- We can't compare values using isnan in a np array.
- np.nan_to_num(array, nan=value) -> default 0.
- np.isinf(array) -> Returns Boolean.
    - if num in array isinf then Returns True
    - positive infinity -> posinf
    - negative infinity -> neginf
    - while replacing with nan_to_num use these; don't use nan=value.
